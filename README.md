# 自社サイトの価格・在庫チェック

先週出した一覧を上げて、自社の公開カタログを取り、変わった行だけを Excel に残します。価格改定の反映・売り切れ放置・新着・掲載落ちを、目視ではなく差で確認する想定です。

> [!note]
> クラウドソーシング向けポートフォリオの2本目です。デモは架空店「和洋雑貨 かもめ堂」の同梱カタログです。実在のネットショップや他社サイトは叩きません。納品時は [`src/shop_config.py`](src/shop_config.py) を御社の公開一覧に差し替えます。

## デモ

- ローカル起動：下記「起動方法」
- 操作の流れ：`操作マニュアル.md`
- 先週サンプル：[`samples/先週取得.csv`](samples/先週取得.csv)

（公開用の90秒動画は、デモが動いたあとで README 先頭に貼ります）

## できること

- 自社の公開カタログから、商品コード・商品名・価格・在庫を取得する
- 先週の Excel / CSV と比べて、値下がり・値上がり・新着・売り切れ・再入荷・掲載終了を出す
- 商品コードで突合する（名前を変えても新規扱いにしない）
- 取れなかった行は失敗ログに残し、今回一覧と変化には含めない

## できないこと

- 任意の URL を入力して取得する（他社サイトを叩けてしまうため）
- ログインが必要なサイト、個人情報の取得
- Amazon・楽天・Yahoo!ショッピングなどの大手モール
- Google スプレッドシートへの自動書き込み（案件では差し替え可）
- Slack / メール通知
- アプリを常時起動した定期実行（先週のファイルを上げる運用、または OS のタスクスケジューラで同じ処理を回す）

御社の公開ページに合わせる改修は、対象URLと「取ってよい範囲」をもらえれば対応できます。差し替え先は `src/shop_config.py` です。

## 画面の使い方

左の監視パネルで先週の一覧を上げ、「取得して比較する」を押します。結果は変化タブを先に出すダッシュボード形式です。手元にファイルが無いときは、先週サンプルをダウンロードしてから上げてください。

1. （任意）先週サンプル CSV をダウンロードする
2. 先週の一覧を上げて実行する
3. 変化・失敗ログ・今回一覧を確認し、結果 Excel を保存する

結果ブックのシート：

| シート | 内容 |
|---|---|
| 今回一覧 | いま取得した商品コード・価格・在庫 |
| 変化 | 先週との差。値下がり・売り切れはオレンジ、値上がりは水色、新着・再入荷はミント、掲載終了はグレー |
| 失敗ログ | 取れなかったページや、欠けた項目 |
| 取得ルール | 自社公開ページのみ、robots.txt、間隔、取らないもの |
| 処理メモ | 件数と取得元 |

## 技術スタック

- Python 3.11+
- Streamlit（画面）
- httpx（納品時の取得。失敗時はリトライ）
- BeautifulSoup（HTML から項目を抜く）
- pandas / openpyxl（表と Excel）

静的なページはこの構成です。JavaScript がないと中身が出ないサイトは、取得の部分だけ Playwright に差し替えます。

## 起動方法

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
python generate_sample.py
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

## 工夫した点

- デモは架空の自社店。他社URLは入力できない
- 商品コードで突合するので、商品名の変更を新着扱いにしない
- 売り切れと再入荷を、ただの在庫変化から分けて出す
- 失敗を黙って捨てず、失敗ログに残す
- 1回あたり最大 10 ページ・500 件。引数ではそれ以上にできない
- 変化だけを別シートにする（全部を目視しなくてよい）

## カスタマイズ例

## 想定クライアント
